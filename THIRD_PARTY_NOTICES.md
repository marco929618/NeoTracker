## 2. Analysis projects (NOT included: you download them from the original source)

`tools/install_melanoma_repos.ps1` clones the original repositories onto **your** computer, each with its own
licence. **This repository contains neither their code nor their trained weights.** Do not redistribute them
together with NeoTracker without checking the licence of each one.

| Project | Declared licence | How NeoTracker uses it |
|---|---|---|
| DeborahAdedigba/Melanoma-Detection_App | GPL-3.0 | The models are loaded by `melanoma_batch.py` in the project's environment |
| ukalwa/melanoma-detection | GPL-3.0 | Android app only: not run from the PC |
| VukIG/Melanoma-Detector | Apache-2.0 | Prototype without a model: no analysis |
| vatsal30/Melanoma-Detection | **no licence declared** | The weight files that the user trains/obtains on their own are used; no code from the project is included here |
| soureshmondal/skinsense (online service) | **no licence declared** | HTTP call to the public service only, **optional and off by default** |

A repository without a licence remains covered by copyright (all rights reserved): that is why it is neither
included nor redistributed.

**Note on derived code.** `melanoma_batch.py` contains the definition of some neural networks (a 6-channel CNN,
SE-ResNeXt50 with a linear head) rewritten so that they can be run without the training/interface parts of the
original projects. The architectures are published in the literature; the definitions are short and dictated by
function. If you are an author of one of the projects and think the text should be attributed differently, open an Issue.

## 4. Scientific sources cited

The criteria and references shown in the "Genetics" and "UV index" sections (e.g. Leachman et al. 2009, NCCN
guidelines, WHO Global Solar UV Index, Fajuyigbe & Young 2016) are **cited by reference** with a link to the source,
not reproduced. The NCCN guidelines are proprietary: the program points to the official site.

## 5. Development and test dependencies

Playwright (Apache-2.0) and Chrome, only for the browser tests; bandit (Apache-2.0) for static analysis.
None of them is needed to use the program.
